4. PROBLEMAS ENCONTRADOS Y SOLUCIONES
======================================================================

PROBLEMA 1: UnicodeEncodeError con emojis (🚀, 💡, 🔍, ⚠️)
  Causa: Windows Python usa encoding cp1252 por defecto en la terminal,
         que no soporta caracteres Unicode fuera del rango Basic Latin.
  Solución: Se parcheó graphrag_console.py reemplazando emojis por texto
            ASCII simple [RESPUESTA GRAPHRAG], [AVISO], [GraphRAG Listo], etc.
  Alternativa: Ejecutar con PYTHONUTF8=1 para forzar UTF-8 en Windows Python.

PROBLEMA 2: La API key original de Groq estaba vencida
  Causa: La GROQ_API_KEY anterior expiró (error 401 Unauthorized).
  Solución: Se actualizó con una nueva API key. Verificada con respuesta 200 OK.

PROBLEMA 3: El venv original es de Windows, no funciona directo en WSL
  Solución: Se ejecuta el Windows Python desde WSL usando la ruta completa:
            /mnt/d/.../venv/Scripts/python.exe

======================================================================
5. INSTRUCCIONES DE USO
======================================================================

Para ejecutar en modo interactivo (Windows CMD o PowerShell):
  cd /d D:\PyCode\ResumenTokensJurisprudencias
  set PYTHONUTF8=1
  venv\Scripts\python graphrag_console.py

Para consulta directa (una sola pregunta):
  venv\Scripts\python graphrag_console.py --query "tu pregunta"

Para re-ingestar datos desde los archivos JSON fuente:
  venv\Scripts\python graphrag_console.py --ingest

Comandos dentro del modo interactivo:
  - Escribe tu pregunta y presiona Enter
  - Escribe '\q' para salir
  - Ctrl+C para interrumpir
