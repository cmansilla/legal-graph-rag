KGraph Resoluciones V3

Motor de consultas jurisprudenciales basado en GraphRAG

Sistema de Generación Aumentada por Recuperación (RAG) especializado en resoluciones del Tribunal Fiscal, Corte Suprema y Tribunal Constitucional del Perú. Combina búsqueda semántica vectorial (FAISS), topología de grafos (NetworkX) y un modelo de lenguaje (Groq) para producir respuestas estructuradas con citas textuales.

Arquitectura

Una consulta en lenguaje natural se convierte en un vector mediante Sentence Transformers, se recuperan los documentos más similares vía FAISS, se expande el contexto con relaciones del grafo NetworkX (jueces, leyes, partes procesales), y se envía todo a un LLM que estructura la respuesta en dos escenarios posibles: datos relevantes (análisis en 4 partes) o datos insuficientes (respuesta concisa con los fallos encontrados).

Componentes

FAISS (4500 vectores) NetworkX (21 732 nodos) Sentence Transformers Groq llama-3.3-70b Python CLI Streaming

Uso

python graphrag_console.py --query "despido arbitrario reposicion"
python graphrag_console.py --query "violencia familiar" --stream
